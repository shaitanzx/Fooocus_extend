## What the Extension is For
([Читать на русском языке](#для-чего-нужно-расширение))

`OneButtonPrompt` automatically generates a positive prompt from thematic lists: it selects an object, character, animal, location, or concept, and then adds style, image type, details, lighting, and other elements to the description. The extension integrates into the standard Fooocus generation workflow.

The **OneButtonPrompt** tab contains one main **Enabled** toggle and four sections: **Main**, **Prompt assist**, **Advanced**, and **Negative prompt**. The Main settings become available after selecting the **Custom...** preset.

## Quick First Launch

1. In the standard Fooocus interface, select the model, resolution, Fooocus style, and other image parameters as you normally would.
2. Open the **OneButtonPrompt** tab and enable **Enabled**.
3. In **Main → One Button Preset**, leave **Standard** for random but structured ideas. If you need a narrower theme, choose a suitable ready-made preset.
4. Click the main **Generate** button in Fooocus.

In the standard automatic mode, the content of the Fooocus positive prompt field is replaced by the text generated by OneButtonPrompt. To control the theme, use the preset settings, prefix/suffix fields, or Prompt assist mode. During a normal run, the existing Fooocus negative prompt may be preserved and supplemented with automatically generated prohibitions.

## Main Toggle and Presets

### Enabled

**Enabled** is turned off by default. While it is off, OneButtonPrompt does not change the prompt or trigger additional iterations. Enable it if you want the extension to participate in the next Fooocus run. This setting applies to the main generation task and to supported image operations where Fooocus processes the prompt.

### One Button Preset

Presets are ready-made sets of parameters that limit the theme and character of the random prompt. In normal mode, the details of the set are hidden but used by the generator. Select **Custom...** if you want to see and edit individual parameters.

The **All (random)...** item selects a random preset when building the prompt. It can use both built-in and saved user presets. **Standard** is the original universal mode with the subject `all`, style `all`, image type `all`, complexity 5, and a 1 in 20 chance of a special mode.

The supplied set of presets includes:

- **Standard** — diverse random plots for general purposes.
- **Consistent results** — a more restrained, repeatable set of styles and card names.
- **Unique People Portraits** — photographic-style portraits of people.
- **Artful People Portraits** — characters with artistic styles and authors.
- **D&D Style Portraits** — fantasy portraits.
- **Cybernetic Animals** — animals with sci-fi and cybernetic elements.
- **Greg mode - The Preset** — characters with a corresponding set of artists and a digital style.
- **Cyberpunk Characters** — characters and neon cyberpunk motifs.
- **Waifu's** and **Husbando's** — female and male anime characters.
- **Fashion Models** — fashion photography and clothing.
- **WIERD HATS** — characters with unusual headwear.
- **Wallpaper art** — conceptual images with a wallpaper-oriented composition.
- **The Cauldron** — mixed concepts and a mode focused on a theme.
- **The Connaisseur** — artistic styles and lines of poetry.
- **Interesting Landscapes** and **Videogame Landscapes** — landscapes, including gaming ones.
- **Relaxing Seascapes** — seascape paintings in a picturesque presentation.
- **Architecture** and **Nature** — architectural and natural plots.
- **Let the CFG sort it out** — a free combination of concepts and descriptions.
- **Now this is podracing** — extremely random, keyword-saturated prompts.

The names reflect the direction of the preset, not a guaranteed exact result: the outcome also depends on the checkpoint, Fooocus styles, and random element selection.

### Preset prefix / Preset suffix

These fields add text before and after the prompt of the selected ready-made preset. They can be used for model trigger words, a general style, or LoRA tags. They are available in preset mode but are hidden when **Custom...** is selected. These are general add-ons to the preset; they are not part of the parameter set saved by the **Save as preset** button.

### Save as preset

In **Custom...** mode, enter a name and click **Save as preset**. The set will appear in the preset list. If you save it under an already existing name, the corresponding set will be overwritten. The user settings file is located at `extentions/obp/userfiles/obp_presets.json`.

## Main: Automatic Prompt Parameters

These parameters affect the automatic construction of the prompt and the five variants created by the **Generate me some prompts!** button. They do not apply to the variation of already entered text in Prompt assist mode.

### Higher levels increases complexity and randomness of generated prompt

Complexity slider — from 1 to 10, default 5. The higher the value, the more random details and unusual combinations may end up in the prompt. For a predictable result, start with 2–4; for variety, leave it at 5–7. Values of 9–10 usually yield more chaotic descriptions.

### Subject Types

Choose what will be the main object of the prompt. Options are grouped by theme: **object** (thing, vehicle, food, building, space, plants), **animal** (including cats, dogs, birds, insects, marine animals), **human** (ordinary people, relationships, celebrities, fictional characters, humanoids, professions, names, or multiple people), **landscape** (ordinary, fantasy, sci-fi, gaming, biome, or city), and **concept** (events, "X of Y" concepts, lines of poetry/songs, card and episode names, mixed concepts). The `all` option allows the generator to choose between groups.

Available items are formed from the extension's list configuration. For a precise theme, choose a specific item directly in **Subject Types**, for example, `object - vehicle` or `human - fictional`. The tab also shows dropdowns for **Type of object**, **Type of humanoids**, and **Type of concept**, but in the tested version, their selected value is overridden in the generator by the subtype already encoded in **Subject Types**. Therefore, to select a subtype, rely primarily on the main list.

### Artists

Selects which artistic authors, styles, or categories may appear in the prompt. Values like **all**, **all (wild)**, **popular**, **greg mode**, and thematic categories (e.g., **anime**, **photography**, **portrait**, **architecture**, **fashion**, **watercolor**) control the selection from corresponding lists; **none** disables the addition of artists. Additional user artist lists, if present in the userfiles folder, may also appear in this dropdown. When working with a highly specialized checkpoint, try limiting the category or choosing **none** if random names interfere with the model's style.

### Type of image

Determines the artistic presentation the generator adds to the theme. Main values: **all**, **all - force multiple**, **all - anime**, **none**, **photograph**, **octane render**, **digital art**, **concept art**, **painting**, **portrait**, **anime**, and **only other types**. The list also contains special modes:

- **only templates mode** — selects a prompt template instead of normal construction.
- **dynamic templates mode** — assembles text based on dynamic templates.
- **art blaster mode** — shifts the result toward authors, artistic movements, and styles.
- **quality vomit mode** — adds many quality and formatting markers; the name does not mean quality is guaranteed.
- **color cannon mode** — emphasizes color combinations and mood.
- **unique art mode** — uses unusual artistic techniques and materials.
- **massive madness mode** — creates a particularly chaotic set of keywords.
- **photo fantasy mode** — adds photographic terms, cameras, lenses, and lighting.
- **subject only mode** — reduces attention to stylistic additions and focuses on the main object.
- **fixed styles mode** — selects a style from a set of prepared styles.
- **the tokinator** — an extremely random mode where the code disables part of the normal logic and filtering; use it if you are ready for unexpected results.

With **all** and **all - anime**, a special mode may trigger randomly. The parameter below sets the probability. If you select a special mode directly from the list, you do not need to wait for the probability to trigger.

### One in X chance to use special image type mode

Slider from 1 to 100, default 20. A value of 20 means roughly a one in twenty chance each time the prompt is built; **1** makes the special mode practically mandatory under suitable conditions. In the code, the chance works only when **Type of image** is **all** or **all - anime**, the **Overwrite type of image** field is empty, and the generator is not building a separate list of just artists. With a specific image type or a filled override, this slider does not control the mode.

### Overwrite subject

Text that sets the main subject or character around which the generator builds the rest of the details. For example, `a small red fox` or `an old stone lighthouse`. The field is useful for getting multiple variants of the same idea. For best results, choose a suitable group in **Subject Types**.

### Smart subject

Enabled by default. Tries not to add properties again that are already named in **Overwrite subject**. For example, if the initial theme already specifies clothing, the generator tries not to select another outfit. This is a heuristic, not a strict text check.

### Overwrite outfit

Replaces the random clothing choice with a specified phrase. Applies to the automatically built prompt and generated suggestions. If the selected theme is an object or landscape, this field may have almost no effect on the result.

### Place this in front of generated prompt (prefix) / Place this at back of generated prompt (suffix)

Adds constant text to the beginning or end of the automatically built prompt. Use this for trigger words, desired composition, or general style. These are automatic mode fields, not a way to add text to a Prompt assist variation.

### Overwrite type of image

Always sets the image type/presentation with its own text, for example, `watercolor illustration` or `fashion photography`. If the field is filled, the random probability of special modes is disabled. It has priority over random type selection but does not change the selected Fooocus checkpoint.

### Filter out following properties (comma seperated)

List words or themes separated by commas that should not be taken from the OneButtonPrompt lists, for example, `film grain, purple, cat`. The filter applies to automatic construction and the five suggestions, but not to the variation of an already entered prompt in Prompt assist mode. For a permanent ban, you can edit the user list `extentions/obp/userfiles/antilist.csv`.

## Prompt Assist: Use and Vary Your Own Text

**Prompt assist mode, turns off prompt generation and uses prompt variantion instead** is disabled by default. If you enable it, OneButtonPrompt stops building a new plot from lists and takes the positive text from the main Fooocus field. With **Prompt variant** = 0, the text remains without variations. Values from 1 to 10 allow the extension to change words and details; the higher the number, the more noticeable the possible changes.

To try variants, click **Generate me some prompts!**. Five separate random prompts built based on the Main and Advanced parameters will appear in the fields below. This button does not start image generation and does not automatically transfer the text to the main field. Select a result and click the corresponding button **prompt 1->Prompt** … **prompt 5->Prompt**. Then enable Prompt assist mode if you want Fooocus to use this text without automatically replacing it with a new random plot. Do not leave the main positive field empty if you are using Prompt assist.

In Prompt assist mode, settings like **Subject Types**, **Artists**, **Type of image**, prefix/suffix, compounder, and Flufferizer do not reformat the already entered prompt. However, **Auto generate negative prompt** can still build negative words based on its text.

## Advanced: Additional Parameters

### Base model

Selects the language and tag style for the text created by OneButtonPrompt: **SD1.5**, **SDXL**, **Stable Cascade**, or **Anime Model**. Interface hints describe SD1.5 as less natural language, SDXL as more natural, Stable Cascade as natural text without weights, and Anime Model as focused on characters and tags. This **does not** switch or load a Fooocus model: the actual checkpoint is selected separately in the main interface.

Active during automatic construction and the creation of the five prompts. Variation of existing text via Prompt assist is not rewritten into the style of the selected Base model.

### Flufferizer

Adds a few random words from the extension's dictionary to the end of the prompt. Options are **none**, **dynamic**, **short**, **medium**, **long**. **none** adds nothing. **short** adds about 4–6 elements, **medium** adds 5–8, **long** adds 8–12. **dynamic** chooses the length based on the already created text: a short prompt gets a long addition, and a long one gets a short addition. Works in automatic mode and when creating the five prompts, but not when varying the main text in Prompt assist.

### Prompt enhancer

Default is **none**. **superprompt-v1** passes the description of the main object to the SuperPrompt model, which expands it into more coherent text. The first run may download the model. The enhancer applies during automatic construction and the generation of the five prompts, but not to the variation of existing text in Prompt assist mode.

### Prompt compounder

Values from **1** to **5**, default **1**. A value of 1 gives the usual single prompt. Higher values compose multiple prompts and combine them into one request. For simple use, leave it at 1; for experimentation, try 2. This is not the number of images — the number of images is set separately in Fooocus. In Prompt assist variation, this parameter does not work, but it is taken into account when creating the five new prompts.

### Prompt seperator

Options are **comma**, **AND**, **BREAK**. Specifies which text separator to use when combining parts with a compounder greater than 1. Default is **comma**. The words AND and BREAK themselves do not guarantee separate areas in the image.

### Prompt seperator mode

Options are **none**, **automatic**, **prefix AND prompt + suffix**, **prefix + prefix + prompt + suffix**. This setting is intended for special schemes of composing compound prompts, in particular, for joint use with a compatible regional/Latent Couple processor. In normal generation, leave it at **none**. The **automatic** mode in this adapter checks several old generalized theme names; modern detailed **Subject Types** items may not match them, so the automatic selection of the number of people/objects may work incompletely. OneButtonPrompt itself does not create masks or separate image areas. The setting affects the automatic mode, but not the button for creating five prompts and not the variation of existing text.

### Iteration number

Number of repeated Fooocus passes, from 1 to 32, default 1. With **Enabled** turned on, each pass rebuilds the prompt and launches generation with the selected Fooocus parameters. If Fooocus is set to generate multiple images per run, they use the one built prompt; the next iteration builds a new one. If **Enabled** is off, repetition does not launch.

### Random seed for each iteration

Enabled by default. For the second and subsequent iterations, it changes the seed. Disable it if you want to keep the seed the same across repetitions; the OneButtonPrompt itself may still change randomly. The field only makes sense when **Enabled** is on and **Iteration number** is greater than 1.

## Negative Prompt: Negative Words

### Auto generate negative prompt

Enabled by default. OneButtonPrompt picks negative words based on the positive description and appends the already entered Fooocus negative prompt to the end of the result. Disable this setting if you want to leave the negative field without automatic additions.

### Enable base enhancement prompt

Disabled by default. When enabled, it adds a base set of negative words related to low quality, artifacts, blurriness, signatures, and similar unwanted details. Works only together with **Auto generate negative prompt**.

### Randomness of negative prompt (lower is more consistency)

Slider 0–10, default 0. Controls the random removal of some automatically found negative terms: a higher number makes the set less stable and may remove more words. A value of 0 gives the highest repeatability of the list. The setting does not affect the original negative text that the user entered in Fooocus, and does not act if automatic generation is disabled.

## Where to Find Results

After clicking the main **Generate** button, images appear in the standard Fooocus gallery and are saved to the standard Fooocus result path specified by the configuration. OneButtonPrompt in this integration does not have a separate folder for final pictures. The image text is saved along with the standard Fooocus metadata if metadata saving is enabled. The five text prompts remain in the interface fields until you transfer the chosen one to the main field; the prompt suggestion button itself does not create an image file.

## Useful Setting Combinations

**Need a human portrait.** In **One Button Preset**, select **Custom...**. In **Subject Types**, specify `human - generic` or `human - fictional`, in **Artists** select `photography` or `portrait`, and in **Type of image** select `portrait` or `photograph`. Leave complexity at 3–5.

**Need the same character in different scenes.** Fill in **Overwrite subject**, choose a suitable **Subject Types** group, and leave **Smart subject** enabled. Add the desired constant style to prefix/suffix. For multiple sequential results, increase **Iteration number**; leave the random seed between passes enabled.

**Want to tweak your own ready-made prompt without replacing it.** Paste the text into the Fooocus positive field, open **Prompt assist**, enable **Prompt assist mode**, and start with **Prompt variant** = 0–2. If you first want to find the right phrasing, generate five prompts and transfer a suitable one via `prompt n->Prompt`.

**Need a cleaner, more repeatable negative prompt.** Leave **Auto generate negative prompt** enabled, and set **Randomness of negative prompt** to 0. Enable **Enable base enhancement prompt** only if you want to add a general list of prohibitions.

## Troubleshooting

- **The Fooocus positive prompt was replaced.** This is normal behavior for the automatic mode. Enable **Prompt assist mode** to use the Fooocus field as the source text, or disable **Enabled**.
- **The prompt does not change with the extension enabled.** Check that **Enabled** is on and that you are not in pure final upscale, Enhance, or ADetailer modes: prompt processing is skipped there.
- **The Prompt assist variant is empty or does not resemble the desired theme.** Specify the source text in the Fooocus positive field; a value of 0 keeps it closer to the original, while higher values produce more noticeable changes.
- **The special style does not trigger randomly.** Check that **Type of image** is set to **all** or **all - anime**, and **Overwrite type of image** is empty. Decrease the number in **One in X chance...** to increase the probability.
- **The desired category is missing in Subject Types.** The list is built from the local OneButtonPrompt category configuration. Start with an available close category; do not confuse the main filter with hidden/unsuitable additional subtypes.
- **SuperPrompt gives an error or responds slowly.** This is a separate text model that may download on first use. First, return **Prompt enhancer** to **none**.

## Для чего нужно расширение
([Read in English](#what-the-extension-is-for))

`OneButtonPrompt` автоматически составляет положительный промпт из тематических списков: выбирает объект, персонажа, животное, место или концепцию, а затем добавляет к описанию стиль, тип изображения, детали, освещение и другие элементы. Расширение встраивается в обычнуй редим генерации.

Вкладка **OneButtonPrompt** содержит один общий переключатель **Enabled** и четыре раздела: **Main**, **Prompt assist**, **Advanced** и **Negative prompt**. Настройки Main доступны после выбора пресета **Custom...**. 

## Быстрый первый запуск

1. В обычном интерфейсе Fooocus выберите модель, размер, стиль Fooocus и остальные параметры изображения так, как обычно.
2. Откройте вкладку **OneButtonPrompt** и включите **Enabled**.
3. В **Main → One Button Preset** оставьте **Standard** для случайных, но структурированных идей. Если нужна более узкая тема, выберите подходящий готовый пресет.
4. Нажмите основную кнопку **Generate** Fooocus.

В стандартном автоматическом режиме содержимое положительного поля Fooocus заменяется текстом, который составил OneButtonPrompt. Чтобы управлять темой, используйте настройки пресета, поля prefix/suffix либо режим Prompt assist. При обычном запуске существующий отрицательный промпт Fooocus может сохраняться и дополняться автоматически сформированными запретами.

## Главный переключатель и пресеты

### Enabled

**Enabled** по умолчанию выключен. Пока он выключен, OneButtonPrompt не меняет промпт и не запускает дополнительные итерации. Включите его, если хотите, чтобы расширение участвовало в следующем запуске Fooocus. Настройка применяется к основной задаче генерации и к поддерживаемым операциям с изображением, где Fooocus обрабатывает промпт.

### One Button Preset

Пресеты — готовые наборы параметров, которые ограничивают тему и характер случайного промпта. В обычном режиме детали набора скрыты, но используются генератором. Выберите **Custom...**, если хотите увидеть и редактировать отдельные параметры.

Пункт **All (random)...** выбирает случайный пресет при построении промпта. Он может использовать как встроенные, так и сохранённые пользовательские пресеты. **Standard** — исходный универсальный режим с предметом `all`, стилем `all`, типом изображения `all`, сложностью 5 и шансом специального режима 1 из 20.

В поставляемом наборе пресетов есть:

- **Standard** — разнообразные случайные сюжеты общего назначения.
- **Consistent results** — более сдержанный, повторяемый набор стилей и названий карточек.
- **Unique People Portraits** — портреты людей в фотографическом направлении.
- **Artful People Portraits** — персонажи с художественными стилями и авторами.
- **D&D Style Portraits** — фэнтезийные портреты.
- **Cybernetic Animals** — животные с научно-фантастическими и кибернетическими элементами.
- **Greg mode - The Preset** — персонажи с соответствующим набором художников и цифровым стилем.
- **Cyberpunk Characters** — персонажи и неоновые киберпанк-мотивы.
- **Waifu's** и **Husbando's** — аниме-персонажи женского и мужского пола.
- **Fashion Models** — модные фотосъёмки и одежда.
- **WIERD HATS** — персонажи с необычными головными уборами.
- **Wallpaper art** — концептуальные изображения с композицией под обои.
- **The Cauldron** — смешанные концепции и режим, сосредоточенный на теме.
- **The Connaisseur** — художественные стили и строки стихов.
- **Interesting Landscapes** и **Videogame Landscapes** — пейзажи, в том числе игровые.
- **Relaxing Seascapes** — морские пейзажи в живописной подаче.
- **Architecture** и **Nature** — архитектурные и природные сюжеты.
- **Let the CFG sort it out** — свободное сочетание концепций и описаний.
- **Now this is podracing** — предельно случайные, насыщенные ключевыми словами промпты.

Названия отражают направленность пресета, а не гарантируют точный результат: итог также зависит от checkpoint, стилей Fooocus и случайного выбора элементов.

### Preset prefix / Preset suffix

Эти поля добавляют текст перед и после промпта выбранного готового пресета. Их можно использовать для триггерных слов модели, общего стиля или LoRA-тегов. Они доступны в режиме пресета, но скрываются при выборе **Custom...**. Это общие надстройки над пресетом; они не входят в набор параметров, который сохраняется кнопкой **Save as preset**.

### Save as preset

В режиме **Custom...** введите название и нажмите **Save as preset**. Набор появится в списке пресетов. Если сохранить его под уже существующим названием, соответствующий набор будет перезаписан. Файл пользовательских настроек находится в `extentions/obp/userfiles/obp_presets.json`.

## Main: параметры автоматического промпта

Эти параметры влияют на автоматическое составление промпта и на пять вариантов, которые создаёт кнопка **Generate me some prompts!**. Они не применяются к вариации уже введённого текста в Prompt assist mode.

### Higher levels increases complexity and randomness of generated prompt

Ползунок сложности — от 1 до 10, по умолчанию 5. Чем выше значение, тем больше случайных деталей и необычных сочетаний может попасть в промпт. Для предсказуемого результата начните с 2–4; для разнообразия оставьте 5–7. Значения 9–10 обычно дают более хаотичные описания. 

### Subject Types

Выберите, что будет главным объектом промпта. Варианты сгруппированы по темам: **object** (вещь, транспорт, еда, здание, космос, растения), **animal** (в том числе кошки, собаки, птицы, насекомые, морские животные), **human** (обычные люди, отношения, знаменитости, вымышленные персонажи, гуманоиды, профессии, имена или несколько людей), **landscape** (обычный, фэнтезийный, научно-фантастический, игровой, биом или город) и **concept** (события, концепции «X of Y», строки стихов/песен, названия карточек и эпизодов, смешанные концепции). Вариант `all` разрешает генератору выбирать между группами.

Доступные пункты формируются из конфигурации списков расширения. Для точной темы выбирайте конкретный пункт непосредственно в **Subject Types**, например `object - vehicle` или `human - fictional`. Вкладка также показывает выпадающие списки **Type of object**, **Type of humanoids** и **Type of concept**, но в проверенной версии их выбранное значение в генераторе переопределяется подтипом, уже закодированным в **Subject Types**. Поэтому для выбора подтипа ориентируйтесь прежде всего на основной список.

### Artists

Выбирает, какие художественные авторы, стили или категории могут появиться в промпте. Значения **all**, **all (wild)**, **popular**, **greg mode** и тематические категории (например, **anime**, **photography**, **portrait**, **architecture**, **fashion**, **watercolor**) управляют выбором из соответствующих списков; **none** отключает добавление художников. Дополнительные пользовательские списки художников, если они есть в папке userfiles, также могут появляться в этом выпадающем списке. При работе с узкоспециализированным checkpoint попробуйте ограничить категорию или выбрать **none**, если случайные имена мешают стилю модели.

### Type of image

Определяет художественную подачу, которую генератор добавляет к теме. Основные значения: **all**, **all - force multiple**, **all - anime**, **none**, **photograph**, **octane render**, **digital art**, **concept art**, **painting**, **portrait**, **anime** и **only other types**. Список также содержит специальные режимы:

- **only templates mode** — выбирает заготовку промпта вместо обычного построения.
- **dynamic templates mode** — собирает текст на основе динамических шаблонов.
- **art blaster mode** — смещает результат к авторам, художественным направлениям и стилям.
- **quality vomit mode** — добавляет много маркеров качества и оформления; название не означает, что качество гарантировано.
- **color cannon mode** — делает упор на цветовые сочетания и настроение.
- **unique art mode** — использует необычные художественные техники и материалы.
- **massive madness mode** — создаёт особенно хаотичный набор ключевых слов.
- **photo fantasy mode** — добавляет фотографические термины, камеры, объективы и свет.
- **subject only mode** — сокращает внимание к стилевым добавкам и концентрируется на главном объекте.
- **fixed styles mode** — выбирает стиль из набора заготовленных стилей.
- **the tokinator** — крайне случайный режим, в котором код отключает часть обычной логики и фильтрации; используйте его, если готовы к неожиданным результатам.

При **all** и **all - anime** специальный режим может включаться случайно. Параметр ниже задаёт вероятность. Если выбрать специальный режим прямо в списке, ждать срабатывания вероятности не нужно.

### One in X chance to use special image type mode

Ползунок от 1 до 100, по умолчанию 20. Значение 20 означает примерно один шанс из двадцати при каждом построении промпта; **1** делает специальный режим практически обязательным при подходящих условиях. В коде шанс работает, только когда **Type of image** — **all** или **all - anime**, поле **Overwrite type of image** пустое и генератор не строит отдельный список только художников. При конкретном типе изображения либо заполненном переопределении этот ползунок не управляет режимом.

### Overwrite subject

Текст, который задаёт главный предмет или персонажа, вокруг которого генератор строит остальные детали. Например, `a small red fox` или `an old stone lighthouse`. Поле полезно для получения нескольких вариантов одной идеи. Для лучших результатов выберите в **Subject Types** подходящую группу.

### Smart subject

По умолчанию включён. Пытается не добавлять повторно свойства, уже названные в **Overwrite subject**. Например, если в исходной теме уже указана одежда, генератор старается не выбирать ещё один наряд. Это эвристика, а не строгая проверка текста.

### Overwrite outfit

Заменяет случайный выбор одежды заданной фразой. Применяется к автоматически построенному промпту и к генерируемым предложениям. Если выбранная тема — объект или пейзаж, это поле может почти не повлиять на результат.

### Place this in front of generated prompt (prefix) / Place this at back of generated prompt (suffix)

Добавляют постоянный текст в начало или конец автоматически построенного промпта. Используйте для триггерных слов, желаемой композиции или общего стиля. Это поля автоматического режима, а не способ добавить текст к Prompt assist-вариации.

### Overwrite type of image

Всегда задаёт тип/подачу изображения своим текстом, например `watercolor illustration` или `fashion photography`. Если поле заполнено, случайная вероятность специальных режимов отключается. Оно имеет приоритет перед случайным выбором типа, но не меняет выбранный checkpoint Fooocus.

### Filter out following properties (comma seperated)

Перечислите через запятую слова или темы, которые не следует брать из списков OneButtonPrompt, например `film grain, purple, cat`. Фильтр применяется к автоматическому построению и к пяти предложениям, но не к вариации уже введённого промпта в Prompt assist mode. Для постоянного запрета можно редактировать пользовательский список `extentions/obp/userfiles/antilist.csv`.

## Prompt assist: использовать и варьировать свой текст

**Prompt assist mode, turns off prompt generation and uses prompt variantion instead** по умолчанию выключен. Если включить его, OneButtonPrompt перестаёт строить новый сюжет из списков и берёт положительный текст из основного поля Fooocus. При **Prompt variant** = 0 текст остаётся без вариаций. Значения от 1 до 10 разрешают расширению менять слова и детали; чем выше число, тем заметнее возможные изменения.

Чтобы попробовать варианты, нажмите **Generate me some prompts!**. В пяти полях ниже появятся отдельные случайные подсказки, построенные по параметрам Main и Advanced. Эта кнопка не запускает генерацию изображения и сама не переносит текст в главное поле. Выберите результат и нажмите соответствующую кнопку **prompt 1->Prompt** … **prompt 5->Prompt**. Затем включите Prompt assist mode, если хотите, чтобы Fooocus использовал этот текст без автоматической замены на новый случайный сюжет. Не оставляйте главное положительное поле пустым, если используете Prompt assist.

При Prompt assist mode настройки **Subject Types**, **Artists**, **Type of image**, prefix/suffix, compounder и Flufferizer не переформатируют уже введённый промпт. Однако **Auto generate negative prompt** всё ещё может построить отрицательные слова по его тексту.

## Advanced: дополнительные параметры

### Base model

Выбирает стиль языка и тегов для создаваемого OneButtonPrompt текста: **SD1.5**, **SDXL**, **Stable Cascade** или **Anime Model**. Подсказки интерфейса описывают SD1.5 как менее естественный язык, SDXL как более естественный, Stable Cascade — как естественный текст без весов, Anime Model — как ориентированный на персонажей и теги. Это **не** переключает и не загружает модель Fooocus: настоящий checkpoint выбирается отдельно в основном интерфейсе.

Активно при автоматическом построении и создании пяти подсказок. Вариация существующего текста через Prompt assist не переписывается в стиль выбранного Base model.

### Flufferizer

Добавляет несколько случайных слов из словаря расширения в конец промпта. Варианты — **none**, **dynamic**, **short**, **medium**, **long**. **none** ничего не добавляет. **short** добавляет примерно 4–6 элементов, **medium** — 5–8, **long** — 8–12. **dynamic** выбирает длину по уже созданному тексту: короткий промпт получает длинное дополнение, а длинный — короткое. Работает в автоматическом режиме и при создании пяти подсказок, но не при вариации основного текста Prompt assist.

### Prompt enhancer

По умолчанию **none**. **superprompt-v1** передаёт описание главного объекта модели SuperPrompt, которая разворачивает его в более связный текст. Первый запуск может скачать модель. Усилитель применяется при автоматическом построении и генерации пяти подсказок, но не к вариации существующего текста в Prompt assist mode.

### Prompt compounder

Значения — от **1** до **5**, по умолчанию **1**. Значение 1 даёт обычный один промпт. Более высокие значения составляют несколько промптов и объединяют их одним запросом. Для простого использования оставьте 1; для эксперимента попробуйте 2. Это не количество изображений — количество изображений задаётся отдельно в Fooocus. В Prompt assist-вариации этот параметр не работает, но учитывается при создании пяти новых подсказок.

### Prompt seperator

Варианты — **comma**, **AND**, **BREAK**. Указывает, каким текстовым разделителем объединять части при compounder больше 1. По умолчанию **comma**. Сами по себе слова AND и BREAK не гарантируют раздельные области на изображении.

### Prompt seperator mode

Варианты — **none**, **automatic**, **prefix AND prompt + suffix**, **prefix + prefix + prompt + suffix**. Эта настройка предназначена для специальных схем составления составных промптов, в частности совместного использования с совместимым региональным/Latent Couple-обработчиком. В обычной генерации оставьте **none**. Режим **automatic** в этом адаптере проверяет несколько старых обобщённых названий тем; современные детальные пункты **Subject Types** могут не совпасть с ними, поэтому автоматический подбор количества людей/объектов способен работать неполно. Сам OneButtonPrompt не создаёт маски или отдельные области изображения. Настройка действует на автоматический режим, но не на кнопку создания пяти подсказок и не на вариацию существующего текста. 

### Iteration number

Число повторных проходов Fooocus, от 1 до 32, по умолчанию 1. При включённом **Enabled** каждый проход заново строит промпт и запускает генерацию с выбранными параметрами Fooocus. Если в Fooocus выставлено несколько изображений на один запуск, они используют один построенный промпт; следующая итерация составляет новый. Если **Enabled** выключен, повторение не запускается.

### Random seed for each iteration

По умолчанию включено. Для второй и следующих итераций меняет seed. Отключите его, если хотите оставить seed одинаковым при повторениях; сам промпт OneButtonPrompt всё равно может меняться случайно. Поле имеет смысл только при **Enabled** и **Iteration number** больше 1.

## Negative prompt: отрицательные слова

### Auto generate negative prompt

Включено по умолчанию. OneButtonPrompt подбирает отрицательные слова по положительному описанию и добавляет уже введённый отрицательный промпт Fooocus в конец результата. Выключите настройку, если хотите оставить отрицательное поле без автоматических дополнений.

### Enable base enhancement prompt

По умолчанию выключено. При включении добавляет базовый набор отрицательных слов, относящихся к низкому качеству, артефактам, размытиям, подписям и подобным нежелательным деталям. Работает только вместе с **Auto generate negative prompt**.

### Randomness of negative prompt (lower is more consistency)

Ползунок 0–10, по умолчанию 0. Управляет случайным удалением части автоматически найденных отрицательных терминов: большее число делает набор менее стабильным и может убирать больше слов. Значение 0 даёт наибольшую повторяемость списка. Настройка не влияет на исходный отрицательный текст, который пользователь ввёл в Fooocus, и не действует, если автоматическое формирование выключено.

## Где искать результат

После нажатия основной кнопки **Generate** изображения появляются в обычной галерее Fooocus и сохраняются по стандартному пути результатов Fooocus, заданному конфигурацией. У OneButtonPrompt в этой интеграции нет отдельной папки для конечных картинок. Текст изображения сохраняется вместе с обычными метаданными Fooocus, если сохранение метаданных включено. Пять текстовых подсказок остаются в полях интерфейса, пока вы не перенесёте выбранную в главное поле; сама кнопка подсказок файл изображения не создаёт.

## Полезные сочетания настроек

**Нужен портрет человека.** В **One Button Preset** выберите **Custom...**. В **Subject Types** укажите `human - generic` или `human - fictional`, в **Artists** — `photography` или `portrait`, а в **Type of image** — `portrait` или `photograph`. Оставьте сложность 3–5.

**Нужен один и тот же герой в разных сценах.** Заполните **Overwrite subject**, выберите подходящую группу **Subject Types**, оставьте **Smart subject** включённым. Добавьте желаемый постоянный стиль в prefix/suffix. Для нескольких последовательных результатов повысьте **Iteration number**; случайный seed между проходами оставьте включённым.

**Хотите поправить свой готовый промпт, не заменяя его.** Вставьте текст в положительное поле Fooocus, откройте **Prompt assist**, включите **Prompt assist mode** и начните с **Prompt variant** = 0–2. Если сначала хотите подобрать формулировку, создайте пять подсказок и перенесите подходящую через `prompt n->Prompt`.

**Нужен более чистый, повторяемый отрицательный промпт.** Оставьте **Auto generate negative prompt** включённым, а **Randomness of negative prompt** — на 0. Включите **Enable base enhancement prompt**, только если хотите добавить и общий список запретов.

## Если результат не соответствует настройке

- **Положительный промпт Fooocus заменился.** Это нормальное поведение автоматического режима. Включите **Prompt assist mode**, чтобы использовать поле Fooocus как исходный текст, или отключите **Enabled**.
- **Промпт не меняется при включённом расширении.** Проверьте, что **Enabled** включён и что вы не находитесь в чистом финальном увеличении, Enhance или ADetailer: там обработка промпта пропускается.
- **Вариант Prompt assist пустой или не похож на желаемую тему.** Укажите исходный текст в положительном поле Fooocus; значение 0 сохраняет его ближе к исходному, большие значения дают более заметные изменения.
- **Специальный стиль не включается случайно.** Проверьте, что **Type of image** стоит на **all** или **all - anime**, а **Overwrite type of image** пустое. Уменьшите число в **One in X chance...**, чтобы повысить шанс.
- **Нужной категории нет в Subject Types.** Список строится по локальной конфигурации категорий OneButtonPrompt. Начните с доступной близкой категории; не путайте основной фильтр со скрытыми/неподходящими дополнительными подтипами.
- **SuperPrompt выдаёт ошибку или долго отвечает.** Это отдельная текстовая модель, которая может скачиваться при первом использовании. Сначала верните **Prompt enhancer** в **none**
